# Visual direction (internal)

## Comparison — previous (teal/ink) vs last ship (volt lime)

| Category | Previous teal/ink | Volt lime |
|----|---|---|
| Contrast | Strong, calm | Harsh lime on near-black |
| Readability | High | Headings compete with accent |
| Hierarchy | Neutral first | Color first |
| Brand | Professional voice/AI | Loud, “theme pack” |
| Professionalism | Wins | Loses |
| AI identity | Scarce teal | Lime + ember + cyan + red |
| Audio | One accent on waveform | Rainbow markers |
| Accessibility | Better body/CTA contrast | Lime CTAs fatiguing |
| Visual noise | Low | Grain + glow + extra hues |
| Memorability | Quiet but coherent | Sticky for the wrong reason |

**Volt does not beat the previous palette.** Restore teal/ink. Keep layout (hairlines, workspace, dark as default). Do not keep lime, ember, grain, or glow.

## Options (restrained)

- **A — Premium Dark (winner):** charcoal layers + one teal accent `#0f766e` / `#2dd4bf`
- **B — Technical/AI:** volt lime — rejected (noise, fatigue)
- **C — Editorial:** warm paper + copper — rejected (weaker AI/lab read)

Light mode is independent: cool gray canvas `#f7f9fb`, white surface, same teal, not an invert of oil-black.
