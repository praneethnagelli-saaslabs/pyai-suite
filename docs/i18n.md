# Internationalization (spec #91)

- English is the first language, but the UI is built for localization from day one.
- All user-facing strings live in per-product `locales/<lang>.json`; components import
  via a `t()` helper — never inline English literals in JSX/markup.
- Numbers, dates, durations, and currency use `Intl` formatters.
- Provider/model names and technical identifiers are not translated.
- RTL layouts supported by the design system where feasible.
