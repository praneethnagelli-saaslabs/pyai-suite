# Empty States (spec #93)

Every empty state teaches the product and offers one-click demo data.

Example:
```
No meetings yet.
Import your first meeting or start a recording.
[Import sample meeting]
```

Rules:
- Lead with a plain-language state ("No calls analyzed yet.").
- Provide the next action as a button, not a link.
- Always include a "[Import sample …]" or "[Run demo]" affordance so the demo
  works within seconds (see demo-mode.md).
- No empty states that merely say "No data."
