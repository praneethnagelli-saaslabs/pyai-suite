# README Structure (spec #96)

Each product README includes, in order:
```
Hero screenshot
One-line pitch
Why this exists
Features
Demo
Architecture
Quick start
Docker
Provider configuration
PyAI setup        ← "Runs on PyAI" + link to PyAI setup
Alternative providers
Development
Testing
Benchmarks
Security
Privacy
Roadmap
Contributing
License
```

Every README states "Runs on PyAI" and links to the PyAI sandbox-key flow. The suite
monorepo root README links all four products to the shared platform docs/.
